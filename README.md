# 🏦 Masrefi (مصرفي) - Personal Finance & Currency Tracker

A clean, responsive, and robust mobile application built with **Flutter** that delivers real-time currency exchange rates and tracks personal financial data. The app integrates with a **RESTful API** for live conversions, features **Clean Architecture**, and provides offline resilience using local storage.

---

## 🌟 Features

- **Real-time Currency Rates:** Fetches up-to-date global exchange rates using REST API.
- **Offline Resilience:** Caches exchange rates and user data locally via `GetStorage` to work seamlessly without internet.
- **Clean Architecture:** Built using a modular 3-layer architecture (Data, Domain, Presentation) for scalability and clean code.
- **Dynamic Localization:** Supports native Arabic (RTL) and English (LTR) language switching with instant state updates.
- **Reactive UI & State Management:** Powered by GetX for lightweight, scalable, and responsive state handling.
- **Optimized Deployment:** Production-ready release APKs generated using `--split-per-abi` for reduced binary sizes.

---

## 🛠️ Tech Stack & Packages

- **Framework:** [Flutter](https://flutter.dev/)
- **Language:** [Dart](https://dart.dev/)
- **Architecture:** Clean Architecture (Data, Domain, Presentation)
- **State Management:** [GetX](https://pub.dev/packages/get)
- **Local Storage:** [GetStorage](https://pub.dev/packages/get_storage)
- **Networking:** REST API & JSON Parsing
